CARICAMENTO
Prima di sovrascrivere, conserva una copia dei file attuali sul server.
Estrai il contenuto dello ZIP nella document root del sottodominio.
Le pagine .html, la cartella assets e la cartella api devono stare allo stesso livello.
Il sito funziona anche staticamente, ma per calendario, risultati e classifica della Serie C
servono PHP e cURL attivi (api/fipav.php). Per controllare: apri
https://foianopallavolo.keyidea.it/api/fipav.php, deve rispondere con dati (JSON).
Senza PHP il sito mostra la copia dei dati salvata nel sito (aggiornata al 17/11/2026).
Nessun database o Node.js necessario. Attiva HTTPS.
